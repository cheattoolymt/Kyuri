# 胡瓜価格、胡瓜食いたい

胡瓜（きゅうり）の卸売相場を、株価チャートのように表示する静的サイトです。
東京都中央卸売市場が公表する日報と、農林水産省の食品価格動向調査を再集計し、
日次・週次・月次・年次・全期間の値動き、各期間の最安値・最高値、月別の平年値、
市場別の水準を可視化します。集計結果は認証不要の JSON API としても公開しています。

GitHub Pages で配信され、データは GitHub Actions が 1 日 1 回自動更新します。

## 収録内容

| 項目 | 内容 |
| --- | --- |
| 価格の単位 | 円 / kg（取引単位あたりの金額を単位 kg 数で除して正規化） |
| 対象品名 | きゅうり（東京都中央卸売市場 日報の「品名」） |
| 対象市場 | 豊洲・大田・豊島・板橋・葛西・北足立・多摩ニュータウン・世田谷・淀橋 |
| 収録期間 | 2021年4月〜（東京都のオープンデータで遡れる範囲） |
| 卸売数量 | 日別の卸売数量（kg）を出来高としてチャートに表示 |
| 小売価格 | 農林水産省 食品価格動向調査（野菜）の全国平均・週次 |

## データ源

1. **東京都中央卸売市場「東京都卸売市場日報（販売結果・価格／数量・青果）」**
   - 東京都オープンデータカタログ（CKAN）から年度別リソースを自動発見
   - ライセンス: クリエイティブ・コモンズ 表示（CC BY）
   - <https://catalog.data.metro.tokyo.lg.jp/dataset/t000013d2000000033>
   - CORS 対応の東京都オープンデータ API（`service.api.metro.tokyo.lg.jp`）も
     `tools/sources.py` の `fetch_wholesale_via_api()` で利用可能
2. **農林水産省「食品価格動向調査（野菜）」の小売価格**
   - `api.cultivationdata.net` の再配布 Web API 経由（JSON・CORS 対応）
   - <https://www.maff.go.jp/j/zyukyu/anpo/kouri/k_yasai/h22index.html>

## 価格と四本値の定義

日報は 1 日単位の集計値であり、株価のような時刻付きの四本値は存在しません。
そのため本プロジェクトでは、その日の建値の分布を四本値として表現します。

| 項目 | 定義 |
| --- | --- |
| 終値 `close` | その日の中値建値の**中央値**。指数としての現在値 |
| 始値 `open` | 前営業日の終値。連続した系列として扱う |
| 高値 `high` | その日の高値建値の中央値 |
| 安値 `low` | その日の安値建値の中央値 |
| `intradayHigh` / `intradayLow` | その日の全建値の最大 / 最小（分布の両端） |

中央値を用いるのは、1 日あたり 20 件前後ある市場別・産地別の建値に
端物や小口由来の飛び値が混じり、単純な最大・最小では値幅が実勢から
大きく乖離するためです。

代表値には相対取引・商物分離・第三者販売の中値を用い、小口の建値が
混ざる「せり・入札」は `auctionMedian` として別に保持しています。
1kg 単価が 80 円未満または 3,000 円超のレコードは、単位表記の誤り由来と
判断して集計から除外します。

期間統計（1週間〜全期間）の高値・安値は、単発の飛び値に引っ張られないよう
**終値ベース**で算出しています。日内レンジは `intradayHigh` / `intradayLow` を参照してください。

## JSON API

ベース URL: `https://cheattoolymt.github.io/Kyuri/api/v1/`

| エンドポイント | 内容 |
| --- | --- |
| `index.json` | 利用可能なエンドポイント一覧 |
| `meta.json` | 生成時刻・データ源・収録期間 |
| `summary.json` | 現在値、前営業日比、各期間の高値・安値・平均、過去最安値と最高値 |
| `lowest.json` | 最安値・最高値のみの軽量版 |
| `daily.json` | 日次の全系列 |
| `daily/{年}.json` | 年別に分割した日次系列 |
| `weekly.json` | ISO 週単位の四本値 |
| `monthly.json` | 月単位の四本値 |
| `yearly.json` | 暦年単位の四本値と平均 |
| `fiscal.json` | 年度（4月始まり）単位の四本値と平均 |
| `seasonality.json` | 月別の平年値 |
| `markets.json` | 直近 90 日の市場別水準 |
| `retail.json` | 全国平均小売価格（週次） |

### 使用例

```bash
# 現在値と過去最安値
curl -s https://cheattoolymt.github.io/Kyuri/api/v1/summary.json \
  | jq '{price: .summary.price, low: .summary.allTime.low}'

# 期間ごとの最安値・最高値
curl -s https://cheattoolymt.github.io/Kyuri/api/v1/lowest.json | jq .windows

# 2025 年の日次系列の 1 件目
curl -s https://cheattoolymt.github.io/Kyuri/api/v1/daily/2025.json | jq '.series[0]'
```

## 操作方法

チャートはマウスだけでなくキーボードでも読み取れます。

| 操作 | 動作 |
| --- | --- |
| クリック / ホバー | クロスヘアを表示し、その日の四本値を読み取り欄に表示 |
| Tab でフォーカス → 左右キー | 1 営業日ずつ移動 |
| Shift + 左右キー | 10 営業日ずつ移動 |
| Home / End | 期間の先頭 / 末尾へ移動 |
| Esc | クロスヘアを解除 |

読み取り欄は `aria-live="polite"` を持つため、スクリーンリーダーでも
値の変化が読み上げられます。

## セットアップ

GitHub Pages の有効化と、データ自動更新ワークフローの配置手順は

## ローカルでの実行

```bash
# データを構築（全年度を取得。初回は 3〜5 分程度かかる）
python3 tools/build_data.py

# 進行中の年度だけ再取得（日次更新と同じ動作）
python3 tools/build_data.py --incremental

# ネットワークを使わずキャッシュのみで再構築
python3 tools/build_data.py --offline

# 生成物の検証
python3 tools/validate.py

# 静的サーバで確認
python3 -m http.server 8080
```

外部ライブラリへの依存はありません（Python 3.11 以上の標準ライブラリのみ）。

## 安定性のための設計

- **キャッシュ層**: 年度 CSV は 30MB 前後あるため、抽出済みの対象行を
  `cache/` に保存し、日次更新では進行中の年度のみ再取得します。
- **フォールバック**: 取得に失敗した年度はキャッシュの内容で継続し、
  外部障害でビルド全体が落ちないようにしています。
- **リトライ**: HTTP 取得は指数バックオフで最大 4 回再試行します。
  4xx（408・429 を除く）は即座に恒久的失敗として扱います。
- **リソース自動発見**: 年度データセットは CKAN 検索で発見するため、
  新年度が追加された場合も設定変更なしで取り込まれます。既知 ID を
  フォールバックとして保持しています。
- **公開前検証**: `tools/validate.py` が四本値の整合、価格の妥当な範囲、
  日付の昇順、summary と系列の一致、API ファイルの JSON 妥当性を確認し、
  異常があれば自動コミットを中止します。
- **依存ゼロ**: Python 標準ライブラリとブラウザ標準 API のみで動作し、
  外部パッケージの更新やサプライチェーンの影響を受けません。

## 更新頻度についての注意

東京都のオープンデータは年度単位の CSV で提供され、更新も概ね年度単位です。
したがってサイトに表示される「現在値」は本日の相場ではなく、
**公表済みデータの最終営業日の値**です。小売価格は週次調査のため、
より新しい時点まで追跡できます。
